# 提示词库：材料科学论文阅读

本页把原始提问整理成可复用提示词模板。使用时，把尖括号中的占位内容替换为你的具体文献或材料体系。

## 1. 全文深度精读

### 提示词模板

```text
请按以下标准阅读附件中的材料科学论文：

1. 用大白话解释这篇文章的科研故事：解决了什么问题、为什么重要、作者是怎么解决的。
2. 解释所有专业词汇和技术词汇。
3. 总结主要创新点。
4. 突出矛盾点、困难点、瓶颈和冲突，并说明作者的思考框架与方法论。
5. 解释每一张主图。
6. 给出你的阅读思路和批判性判断。
7. 讲解要足够细，能把小白带到接近研究者的水平。
8. 提炼可迁移的思维方法、底层设计逻辑和尚未解决的问题。
```

### 期望输出结构

```text
1. 一句话总结
2. 科研问题与瓶颈
3. 大白话故事
4. 专业词汇表
5. 创新点
6. 矛盾点与设计逻辑
7. 逐图解读
8. 机制链条
9. 可迁移方法论
10. 局限性与未来工作
```

## 2. 材料合成与性质逻辑

### 提示词模板

```text
请解释附件论文中材料合成和性质设计的底层逻辑。

请回答：

1. 作者为什么选择这个单体、聚合物、官能团、氧化态、侧链、骨架或嵌段结构？
2. 他们想创造什么样的目标材料状态？
3. 哪些分子间相互作用控制关键性质？
4. 为什么要设计这些对照和比较？
5. 可以提取哪些通用设计规则？
6. 这个逻辑如何迁移到其他材料？
7. 如何用同样的思维开发新材料？
```

### 期望输出结构

```text
1. 目标性质
2. 目标材料状态
3. 关键官能团
4. 合成选择
5. 性质机制
6. 对照实验
7. 通用设计规则
8. 新材料开发流程
```

## 3. 为什么做这些表征实验？

### 提示词模板

```text
请解释附件论文中每个表征或实验为什么必须做。

对每个实验，请说明：

1. 它回答什么问题。
2. 背后的物理或化学原理。
3. 如果假设正确，应该看到什么证据。
4. 它排除了哪些竞争性解释。
5. 它在证据链中的位置。
6. 如果缺少这个实验，论文论证会受什么影响。
```

### 期望输出结构

```text
实验名称
- 问题：
- 原理：
- 关键结果：
- 解读：
- 被排除的替代解释：
- 在证据链中的位置：
```

## 4. 逐图分析

### 提示词模板

```text
请分析附件论文中的每一张主图。

对每张图：

1. 说明这张图想展示什么。
2. 解释每个子图或主要数据块。
3. 指出实验对比关系。
4. 解释关键结果。
5. 说明作者为什么需要这张图。
6. 说明它支持的结论。
7. 指出可能的局限或替代解释。
```

### 期望输出结构

```text
图 N
- 目的：
- 子图解释：
- 关键对比：
- 主要结论：
- 为什么重要：
- 注意事项：
```

## 5. 机制与矛盾点分析

### 提示词模板

```text
请找出这篇文章的核心矛盾或瓶颈。

请解释：

1. 传统方法为什么失败。
2. 问题为什么困难。
3. 作者需要权衡哪些因素。
4. 作者如何把某个限制转化成有用的机制。
5. 作者如何设计对照来验证机制。
6. 什么结果会证伪他们的假设。
```

## 6. 可迁移方法论

### 提示词模板

```text
请从这篇论文中提取可迁移方法论。

请说明如何把这套逻辑迁移到催化剂、电池、膜材料、涂层、传感器、蛋白质制剂、聚合物回收或纳米递送等其他材料体系。

对每个迁移方向：

1. 给出抽象原则。
2. 给出原始体系。
3. 给出目标体系。
4. 说明如何重新设计材料。
5. 定义表征实验。
6. 定义成功标准。
```

### 期望输出结构

```text
抽象原则
原始实现
迁移目标
重设计策略
预期性质
必要表征
成功标准
```

## 7. 新材料开发

## 8. 审稿式局限性分析

### 提示词模板

```text
请作为建设性审稿人，找出附件论文中尚未解决的问题。

请覆盖：

1. 科学层面的局限。
2. 机制上的不确定性。
3. 表征缺口。
4. 稳定性和可放大性问题。
5. 安全或监管问题。
6. 泛化风险。
7. 建议的后续实验。
```

### 期望输出结构

```text
局限
为什么重要
可能风险
缺失证据
建议后续实验
```
